## Evidências e critérios

- `translated`: single contextually used static translation key in the historical source with pt-BR value matching original text and en-US catalog entry. The AST gate verifies key references, not full English linguistic equivalence.
- `non_translatable`: 188 technical entries and historical format/code fragments, including cloud region IDs, AWS/OCI symbols, enums, status codes, schema keys, CSS/SVG and TypeScript fragments. 29 source-level false positives were corrected after inspection.
- `external_content`: 46 current dynamic expressions with traceable origin; the remaining historical backend expressions are in `needs_review` until origin reconfirmation.
- `obsolete`: 149 records in `/dev/ui`, excluded from production by `notFound()`; proxy behavior in staging is unverified.
- `missing_translation`: 8 verified JSX/label literals in production-relevant code, not all runtime routes/states tested; see prioritized gaps file.
- `needs_review`: 616 rows with individual evidence and pending action; no severity inferred solely from absence of exact text.

## Reproducibility / limitations

Run `cd frontend && npm run audit:i18n:baseline` for evidence integrity and deterministic recomputation; `npm run audit:i18n:baseline:write` rebuilds the CSV from AST and may identify additional moved/parameterized contexts. Run `npm run lint:i18n`, `lint:i18n:references` and the incremental coverage scanner with the PR's correct base. The original 25.1 inventory is not changed.

Do not declare complete Phase 25 certification based on this CSV. Front B must test viewer/admin, Billing, Inventory, Flow, Opportunities, RDS Reservations, Collections, Settings and locale/theme combinations in authenticated Chromium with fixtures and capture route/state evidence.
