## Original raster masters and current runtime assets

The original high-quality PNG master inventory below is a **source-kit manifest**, not a list of missing runtime logos. Production branding already uses the official surface-aware high-resolution SVG mappings in `frontend/lib/brand.ts` and assets under `frontend/public/brand/aven/`. The favicon and application icons are also available through the runtime asset map. Keep the original masters separately for future exports or graphics work.

The following original master files are listed for provenance and archival reference. Their presence in the original kit does not imply that each PNG size is a separate runtime dependency. Do not recreate them from screenshots, synthetic wordmarks or approximations.
