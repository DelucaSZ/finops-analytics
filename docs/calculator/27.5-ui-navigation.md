# Task 27.5 — Aven Cloud Cost Calculator UI & Navigation

**Branch:** `feat/task-27.5-calculator-ui-navigation`  
**Scope:** Next.js UI over the existing read-only authenticated calculator APIs. No cloud creation, catalog edits or Billing persistence.

## Página e navegação

- A página autenticada está em `/calculator`; o `AppShell` global continua responsável por sessão, Sidebar, Topbar, idioma e tema.
- A navegação centralizada exibe **Calculadora / Calculator** e o ícone Lucide Calculator, inclusive no menu mobile/Sidebar recolhida.
- `frontend/app/calculator/page.tsx` usa `PageContainer width="full"`, `PageHeader`, `Card`, `Select`, `Input`, `Switch`, `Button`, `Alert`, `Badge` e `EmptyState` oficiais.
- A composição apresenta configuração, resumo financeiro e tabela de componentes. CSS module usa tokens semânticos e `@container aven-page` com fallback `@media`; tabelas têm scroll interno e SKUs longos não expandem a página.

## Contratos por serviço

| Provedor | Serviço | Metadados | Configuração submetida |
| --- | --- | --- | --- |
| AWS | EC2 | GET `/calculator/aws/regions`, GET `/calculator/aws/options?service=ec2&region=...&search=...` | Instância/OS/On-Demand/shared tenancy, gp2/gp3, volume, gp3 IOPS e throughput |
| AWS | RDS | Mesmos endpoints com `service=rds`, `engine` e busca com mínimo de 2 caracteres | PostgreSQL/MySQL/MariaDB, classe, Single/Multi-AZ, gp2/gp3, armazenamento |
| OCI | Compute VM | GET `/calculator/oci/options?service=compute&region=...` | Shapes allowlisted, OCPU, RAM, Linux/Windows, boot volume e volumes extras com VPU e count |
| OCI | DB System | GET `/calculator/oci/options?service=db_system&region=...` | Combos de preço do catálogo; com `setup_required`, simulação diagnóstica na shape informada pelo backend com edição/licença suportadas pelo schema, ECPU e armazenamento, sem valores inventados |

AWS só exibe as instâncias/combinações publicadas no catálogo consultado, sem lista estática de preços. Regiões AWS são carregadas dinamicamente; região OCI é informada pelo usuário, pois a API OCI não fornece lista verificada de regiões. Em OCI, a seleção de shape, SO e VPU é derivada dos metadados; os limites de CPU e RAM são validados.

## Financeiro e períodos

Todos os resultados vêm exclusivamente de `POST /api/v1/calculator/estimate`, via `api()` (cookie, CSRF, timeout, erros de sessão). O cliente não executa cálculo de preços, rateio, desconto, câmbio, imposto ou arredondamento.

- AWS: desconto editável de 0 a 100% (padrão 0), conversão para BRL desligada por padrão, FX manual maior que zero e imposto 13% editável quando conversão está ativa. Todos são parâmetros do engine, não operações de UI.
- OCI: valores BRL finais do catálogo; não há campos de desconto, câmbio ou imposto.
- Período: mensal, horas, dias, semanas e range de data/hora. `datetime-local` é convertido para ISO 8601 UTC mantendo a interpretação do fuso do navegador; o backend calcula a duração efetiva e o rateio.
- Quantidade: 1 a 100.000. Limite do período: cinco anos de 366 dias.
- `priced`: exibe `monthly_final_cost` e `period_final_cost` na moeda `final_currency`, além dos ajustes detalhados AWS quando disponíveis.
- Não precificado ou parcialmente precificado: **não** exibe total definitivo. Mostra somente `monthly_known_subtotal` / `period_known_subtotal` em `pricing_currency` com rótulos de subtotal original/sem ajustes e lista de faltantes.
- A tabela apresenta SKU, unidade, preço por unidade, consumo, custos originais mensal e do período, status e origem/vigência. Os custos por linha são os valores originais do catálogo, não o custo final após ajustes.

Qualquer edição de parâmetros aborta a simulação anterior e limpa seu resultado. A requisição inclui controle de AbortController e contador de sequência para descartar respostas antigas. As consultas de metadados possuem debounce e cancelamento na desmontagem/troca de provedor e região.

## Internacionalização e temas

Todos os rótulos, validações, estados e descrições estão em `frontend/i18n/messages/{pt-BR,en-US}.json`, com novo namespace `calculator`. Valores e datas utilizam `CurrencyDisplay` e `Intl.DateTimeFormat` com a preferência de idioma, sem alterar a moeda do resultado.

O layout usa superfícies e tokens do Theme Engine sem estilos específicos Light/Dark; a auditoria visual integrada e browser E2E permanecem para a Task 27.6/27.7.

## Testes e limitações

`frontend/tests/aven-calculator.test.mjs` cobre contratos de navegação, rotas, tipagem cliente, fontes de preços, cancelamento, estados parciais, período, AWS/OCI, i18n e responsividade estática. Verificar CI com `npm test`, `npm run typecheck`, `npm run build`, `npm run lint:i18n`, `npm run lint:i18n:references` e `npm run lint:design-system:changed`.

Limitações de escopo: sem cotação FX automática; AWS metadata exige IAM `pricing:GetProducts` e `pricing:GetAttributeValues` no backend e acesso AWS Price List; 100 opções por consulta (refinamento da busca para opções adicionais); OCI DB System permite simulação de diagnóstico sem bindings (SKU ausente e total indisponível), mas não calcula preço definitivo antes do cadastro de cada binding/SKU; nenhuma verificação regional de capacidade OCI; custos auxiliares fora dos adapters existentes não são adicionados. A interface não cria recursos e não persiste simulações.
