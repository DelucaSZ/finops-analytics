## 2. Arquitetura e consumidores

`AWS Pricing Bulk API (DescribeServices → ListPriceLists → GetPriceListFileUrl) → download/validação → staging/normalização → PostgreSQL (aws_pricing_products, aws_pricing_rate_details, pricing_catalog_items) → AwsRegionalPricingResolver → Calculadora AWS e AwsPolicyPricingAdapter → Opportunities, reconhecimento e snapshots`.

A fonte central conserva ServiceCode, RegionCode, SKU, Rate Code, atributos, tipo de cobrança, unidade, valor decimal em USD, vigência, versão de origem e batch. O endpoint da Pricing API AWS (por padrão `us-east-1`) **não** deve ser confundido com a região comercial `sa-east-1`/`us-east-1`. A publicação é regional, transacional, rastreável e deve preservar a última versão válida. Preços públicos não são preços contratuais/descontados.

Fluxos administrativos: `GET /api/v1/pricing/aws/*` somente admin; `POST /api/v1/pricing/aws/sync` exige admin recente, CSRF e gate explícito de publicação; o POST enfileira a solicitação, sem importar durante a requisição. O worker executa a fila; o sincronizador periódico permanece desabilitado até autorização. Documentos de implementação: `28.2` a `28.8` nesta pasta.

## 6. Limitações financeiras e integridade histórica

Preço parcial ou ausente não pode gerar economia integral reconhecida nem passar por threshold/ranking como se fosse total. LB com apenas hora-base, snapshot por tamanho lógico e RDS sem todos os componentes não são estimativas totais comprovadas. As interfaces devem mostrar cobertura e ausência de preço. Valores legados sem `evidence.pricing.status` continuam ambíguos quanto à procedência; não reclassificar retroativamente sem trilha e aceite.

Ensaio obrigatório em PostgreSQL isolado: publicar tarifa v1 de teste → coleta simulada → gerar finding/observation → fechar ciclo e snapshot → publicar v2 → nova coleta → verificar tarifa atualizada e snapshot v1 inalterado; repetir para zero legítimo, `NULL`, parcial, USD/BRL, oportunidade tratada/arquivada e reprocessamento idempotente do ledger. O resultado não foi observado nesta sessão.
